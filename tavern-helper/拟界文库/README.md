# «LoreFrame»｜拟界文库

拟界文库是一个运行在酒馆助手中的小剧场脚本。它会结合当前聊天、角色设定与绑定的世界书，把剧情延伸成可阅读、可交互的网页：角色日常、论坛帖子、聊天记录、物品展示……都可以通过小剧场提示词来定制。

当前版本：**1.7.18**

## ✨ 主要功能

- **随剧情生成**：正文回复结束后自动生成，也可以手动生成、指定楼层生成或重新生成候选版本。
- **自定义小剧场**：内置提示词，支持编辑、分组、导入与导出；可设置常驻小剧场，再从候选中随机抽取其他内容。
- **读取角色资料**：使用角色卡、用户设定、绑定世界书和聊天内容，支持调整历史读取深度及世界书条目的纳入范围。
- **剧场配图**：支持 NovelAI 与 GPT Image，可读取柏宝绘的接口、画风与参考图配置，也能设置 API 生图和 CSS 绘画的使用概率。
- **生图编辑**：在剧场左下角选择图片，编辑提示词与配文、重新生成、下载图片或切换历史版本。
- **保存与回看**：按角色和聊天保存剧场，支持收藏、切换候选、修改标题和源码，以及定位原始聊天楼层。
- **外观设置**：支持日夜主题、自定义配色方案、悬浮球与多种打开入口，兼顾桌面和手机使用。
- **独立生成配置**：可沿用酒馆连接或设置第二 API，不读取当前酒馆预设提示词。

## 📦 安装与更新

需要先安装酒馆助手。

推荐下载 [GitHub 版导入文件](https://github.com/colerith/LoreFrame/raw/main/file/loreframe-git-loader.json)，在【酒馆助手】中导入【全局脚本】，保存并启用。也可以将 [GitHub 版 JS](https://github.com/colerith/LoreFrame/raw/main/file/loreframe-git-loader.js) 的完整代码粘贴进已有脚本。

GitHub 版会优先用本地缓存启动，后台检查更新；新版本下载完成后，下次重载脚本生效。已有有效缓存时，临时断网仍可打开文库。升级时只启用一个拟界文库脚本。

需要固定版本时，仍可使用以下导入语句：

```js
import "https://cdn.jsdelivr.net/gh/colerith/LoreFrame@loreframe-v1.7.18/file/loreframe-1.7.18.js";
```

## 🌱 开始使用

1. 打开角色聊天，通过悬浮球进入拟界文库。
2. 在「提示词管理」选择小剧场；需要固定搭配时，在「生成设置」勾选常驻，再设置随机数量与概率。
3. 按需配置第二 API、世界书读取范围及「剧场生图」。
4. 继续聊天等待自动生成，或在文库中手动生成剧场。

剧场保存在当前浏览器中。删除单角色聊天会同步清理对应剧场，包括该聊天的收藏；其他聊天保留，群聊暂不联动。
