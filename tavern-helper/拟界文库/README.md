# 拟界文库 / 线上功能脚本

版本唯一来源为 `release.json`。在模板项目根目录执行 `pnpm release:loreframe` 生成带版本号的发布产物与校验清单，详见 [发布流程](./发布流程.md)。

## 柏宝绘接入

在「剧场生图 → NovelAI 预设配置」点击「读取柏宝绘配置」，可读取当前酒馆已保存的接口、密钥、模型、画幅、采样参数和当前画风。按来源更新导入槽位，保留手工槽位，不修改柏宝绘，不自动启用生图。

在 Vibe 库点击「读取柏宝绘参考图」，选择一项再导入。支持柏宝绘内联数据、当前酒馆 `/user/files/` 文件和本地 IndexedDB；导入后需从 Vibe 库加入当前组。匹配模型的编码直接复用，只有原图时按所选模型编码；只有不匹配编码时提示更换模型或原图，不默默丢弃参考。强度为 0 不发送。

导入是本机配置快照；柏宝绘修改后需再次读取。不会把角色库外貌或全部参考图自动套到每张页面图片中。云端发布只包含源码和构建结果，不包含用户运行时密钥与图库。

## 主题方案与概率生图

在「美化方案 → 主题配色方案」切换「默认 · 森系」或「电波手机 · 蓝粉」。每套方案包含日间/夜间主题色；调整颜色即时生效后，可另存新方案、覆盖所选自定义方案、重命名或删除。内置方案不可覆盖或删除。删除方案保留当前配色；恢复默认不清空自定义方案库。悬浮球独立自定义颜色仍优先于主题色。

在「剧场生图」开启概率选择，设置 0–100% 的 API 命中率：新页面每个图片位置独立选择 API 或 CSS 绘画。命中 API 的图片仍由生图按钮发起请求；CSS 图片不会调用生图接口。关闭概率选择保留原有方式。抽取结果保存在页面 HTML 中，刷新/重试不重抽，修改概率仅影响尚未分配方式的图片。

开启概率选择时，页面生成提示会要求模型为每个图片位置同时提供画面提示词和 CSS 绘画。模型漏掉 CSS 绘画时使用客户端渐变风景兜底，避免空白占位。现有已生成图片保留。

## Claude / Gemini Flash 与 GPT Image

页面生成的消息统一为 `system → user`，取消“收到”占位和末尾 assistant 预填充。主 API、第二 API、重试与提示词预览共用相同的消息组装函数；ECoT 格式要求仍作为完整的 user 指令发送，不作为 assistant 续写前缀。

在「剧场生图」选择 `GPT Image`，填写独立地址、密钥、模型、画幅、质量、图片格式、背景和共用画风。地址留空使用官方服务，也支持代理根路径、`/v1` 或完整生图端点。切换生图方法保留两套设置，GPT Image 使用自然语言图片描述，不发送 NovelAI 的 Vibe、采样和负面提示词参数。

当前 GPT Image 接入用于文生图；点击已有页面的生图按钮时按当前所选接口处理占位图片。返回 Base64 或代理图片链接时都会保存为内嵌图片。透明背景需选 PNG/WebP；超高与最高质量需服务商模型支持。拉取模型列表不会生成图片，可继续手填模型 ID。

接口参数依据 [OpenAI Images 官方文档](https://developers.openai.com/api/reference/resources/images/methods/generate)；本地验证使用模拟响应，不代表真实模型权限、付费出图效果或浏览器跨域连通性已验证。

## 功能介绍

### 页面生成

- 监听酒馆正文回复完成事件，按设置自动生成页面。
- 支持手动生成、指定楼层生成、批量生成，以及对已有页面重新生成候选版本。
- 使用 `generateRaw` 直接请求模型，不读取当前酒馆预设提示词。
- 支持主 API 与第二 API；第二 API 支持 OpenAI 兼容、Google AI Studio、Google Vertex AI。
- 支持流式输出，并在面板里展示生成状态、请求日志和错误信息。
- 支持失败自动重试；默认关闭，默认超时 `360000ms`，最大重试次数 `3`。

### 提示词系统

- 内置基础提示词和小剧场提示词。
- 支持本地新增、编辑、删除、复制、发布与恢复内置小剧场。
- 支持随机小剧场：
  - 可选择多个候选小剧场。
  - 可设置每次抽取数量。
  - 可设置触发概率；当前逻辑为 `roll < probability` 时触发请求，否则跳过本次生成。
- 支持一次性小剧场：临时加入本次生成，不写入长期库。
- 支持提示词预览，能查看本次请求会发送的 system / assistant / user 内容。

### 来源采集

- 采集当前聊天可见楼层、最新用户消息、最新 AI 回复。
- 读取角色卡、用户设定、绑定世界书、激活世界书条目。
- 支持世界书条目纳入/排除开关，并显示世界书总览和本次纳入字数估算。
- 自动提取历史页面中的正文记忆，用于后续页面衔接。
- 对隐藏楼层、不可见内容和被排除内容做过滤，避免误纳入上下文。

### 页面管理

- 每个聊天保存独立页面记录。
- 每条页面记录支持多个候选版本，可前后切换。
- 支持收藏、删除、标题编辑、源码编辑和刷新预览。
- 支持从原始酒馆楼层跳回对应消息。
- 会在酒馆消息楼层旁添加打开按钮，用于快速打开该楼层对应页面。
- 页面主体优先存入 IndexedDB，外壳索引保存在 localStorage / 聊天 metadata 中，以降低 localStorage 配额压力。

### 面板与入口

- 悬浮球入口：可拖拽、可贴边、可自定义图标/颜色/大小。
- QR 按钮入口和扩展菜单入口：可在设置中开关。
- 面板支持拖拽、缩放、全屏、移动端强制全屏。
- 支持日间/夜间/定时主题，并可自定义面板与悬浮球配色。

### 运行设置

- 自动生成开关。
- 聊天历史读取深度。
- 手机端页面缩放。
- 本地缓存上限和当前聊天/全部缓存清理。
- 排除角色卡名单。
- 排除标签，内置标签包含 `echo`、`ta的手机`、`gossip`、`danmu`、`幕后故事`、`日月来信`、`branches`、`horae`。
- 第二 API 多配置档管理、模型列表读取、API 密钥与代理密码保存。
- 脚本初始化与格式化脚本/当前聊天窗口。

## 运行流程

1. `index.ts` 用 `?raw` 读取本目录下的 TypeScript 片段。
2. 所有片段按固定顺序拼接进一个 IIFE。
3. 通过 `new Function()` 执行拼装后的脚本。
4. `host-buttons.ts` 启动挂载流程。
5. `ui-events.ts` 创建 iframe 面板、悬浮球和宿主入口。
6. `monitor.ts` 监听酒馆事件，判断正文生成是否完成。
7. `generation.ts` 调用 `getGenerationPrompt()`、采集来源、构建提示词并发送 `generateRaw` 请求。
8. `prompt-builder.ts` 解析模型返回的 HTML。
9. `online-store.ts` 保存页面、候选版本、正文记忆和缓存索引。
10. `ui-render.ts` 重新渲染页面预览、设置面板、来源面板和调试信息。

## 关键数据

### 设置数据

设置主要由 `settings.ts` 管理，保存到脚本变量与本地存储中。主要包含：

- 当前基础提示词、小剧场、摘要标签选择。
- 自动生成、历史深度、移动端缩放。
- 外观主题与悬浮球样式。
- 第二 API 配置与配置档列表。
- 随机小剧场设置。
- 排除角色与排除标签。
- 本地缓存上限和打开入口设置。

### 页面数据

页面数据主要由 `online-store.ts` 管理，包含：

- 当前聊天的页面记录。
- 每条页面的候选版本、收藏状态、标题、来源楼层。
- 页面 HTML 与提取出的正文记忆。
- 聊天维度索引、角色维度索引、旧版本数据迁移。
- IndexedDB payload 与 localStorage 外壳索引。

### 调试数据

运行时日志保存在内存中，并显示在「调试」页：

- 监听事件。
- 来源采集结果。
- API 请求摘要。
- 解析、保存、重试和错误信息。

## 维护约定

- 本目录文件虽然都是普通 TypeScript，但运行时仍是“按顺序拼接后整体执行”。
- 跨文件依赖依靠 `index.ts` 中 `onlineFeatureParts` 的顺序，不要随意调整。
- 新增片段时：
  1. 在本目录创建新的 `.ts` 文件。
  2. 保持文件内容可作为顶层代码直接拼接。
  3. 在 `index.ts` 中按依赖顺序导入 `?raw`。
  4. 将片段加入 `onlineFeatureParts`。
  5. 更新本 README 的文件树和职责说明。
- 不要在片段里使用 Node.js API；脚本最终运行在浏览器环境。
- 修改设置结构时，同步更新默认值、归一化函数、保存函数、渲染函数和事件绑定。
- 修改存储结构时，保留旧 key 的迁移逻辑，避免用户已有页面丢失。
- 修改 UI 模板时，检查 `ui-render.ts` 和 `ui-events.ts` 是否仍能查到对应 `data-*` 节点。

## 常见排查

- 看不到悬浮球：检查 `host-buttons.ts` 是否执行、宿主页面是否已有旧 iframe、`SCRIPT_ID` 对应 DOM 是否被其他脚本移除。
- 没有自动生成：检查自动生成开关、排除角色/标签、随机小剧场概率、正文完成监听日志。
- 没有发送 API：检查 `generateRaw` 是否存在、第二 API 是否启用且配置完整、提示词是否为空。
- 页面没有保存：检查 IndexedDB 是否可用、localStorage 是否超限、运行日志是否出现保存异常。
- 世界书内容不对：到「来源」页刷新，查看绑定世界书、条目纳入/排除状态和字数估算。
- 面板美化不生效：确认已保存外观设置，并检查当前是日间还是夜间主题。
